# App screenshots

Captured from the minimal-UI debug app on an Android 17/API 37 emulator on 3 November 2026. These are actual app renders, not mockups.

- `library.png`: all six decks, one hero image per fixed 4:3 card, default font scale/density.
- `game.png`: landscape reveal with manual guess controls and Next.
- `famous-people.png`: name-only reveal without a photograph.
- `credits.png`: offline source list including the separately credited microphone cover.
- `game-compact.png`: landscape at 540dpi (320dp screen height), font scale 1.3; image, clue, counter, and Next remain available.

The default emulator uses 1080x2400 pixels at 420dpi. Density and font scale were restored after testing. Earlier 28 October screenshots have been replaced; that physical-device session is recorded historically in `docs/VERIFICATION.md`.
