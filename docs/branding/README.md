# Charades artwork

The card/play mark is a native vector: `charades-mark.svg` for source/reuse and `res/drawable/ic_launcher_foreground.xml` for Android. Launcher icons use the same mark and navy background.

`app/src/main/res/drawable-nodpi/game_night.png` is original branding artwork produced with the built-in image generation tool. It is not a gameplay photograph. Prompt: "Use case: stylized-concept. Asset type: original hero artwork for a native Android picture-charades party game named Charades. Create a beautifully art-directed playful 3D illustration, wide landscape composition around 3:2. A lively fan of chunky rounded picture cards: one card shows an expressive friendly orange tiger, another a little blue-and-cream Eiffel Tower, another a coral dancing figure. A sculpted warm peach hand holds the cards from the lower right, and another hand points playfully from lower left, suggesting acting and guessing. A few restrained glossy coral and cobalt game pieces float near the cards. Tactile matte clay forms with polished studio lighting, soft real shadows, warm friendly sophistication. Cobalt blue #244BE8 and coral #FF806E, paper-white cards with navy details. Entire background uniform very pale ice blue #E8EDFF. Center composition, generous breathing room at edges, no borders, no text, no letters, no logos, no watermarks. This is branding artwork, not a photo and not a screenshot."

Bundled fonts: [Fredoka](https://github.com/google/fonts/tree/main/ofl/fredoka) for playful headings and [Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans) for readable UI. Both are distributed under the SIL Open Font License; see their local license files. Gameplay provenance is separate in `docs/photo_sources.json`.
