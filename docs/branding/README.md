# Charades artwork

The card/play mark is a native vector: `charades-mark.svg` for source/reuse and `res/drawable/ic_launcher_foreground.xml` for Android. Launcher icons use the same mark and navy background.

`app/src/main/res/drawable-nodpi/game_night.png` is original branding artwork produced with the built-in image generation tool. It is not a gameplay photograph. Prompt: "A beautifully art-directed playful 3D illustration, wide landscape composition around 3:2. A fan of chunky rounded picture cards: an expressive orange tiger, a blue-and-cream Eiffel Tower, a coral dancing figure. Warm peach hands hold and point at the cards. Restrained coral/cobalt game pieces. Matte clay forms, polished studio lighting, soft real shadows. Cobalt #244BE8 and coral #FF806E, paper-white cards, navy details, pale ice-blue #E8EDFF background. Center composition, breathing room, no text, logos, borders, or watermarks."

Bundled fonts: [Fredoka](https://github.com/google/fonts/tree/main/ofl/fredoka) for playful headings and [Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans) for readable UI. Both are distributed under the SIL Open Font License; see their local license files. Gameplay provenance is separate in `docs/photo_sources.json`.
